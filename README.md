# Prasanna

Two private, offline apps live in this repository, one per branch:

| Branch | App | What it is |
|---|---|---|
| `aperture` | Aperture | A private, offline AI photo assistant for macOS |
| `orbit` | Orbit (folder `orbit/`) | A private, offline finance and personal assistant. Start with `orbit/README.md` |

Nothing in either app talks to a cloud service while it runs.
