## Evidence classes in this package
- **CI-verified (L):** everything in the tests above, once the exact-head GitHub Actions run is read (posted on PR #8 separately).
- **Developer-reported:** local runs on Python 3.13 and 3.11 (core), the kit suite, and the benchmark numbers in `docs/WP3_6_RELIABILITY.md`.
- **Architect-inspected / owner-verified-on-Mac:** none yet.

## Known limitations, consolidated
1. The SwiftUI app, Keychain, TCC, signing, FileVault and power-loss behaviour are not built or verified (Mac).
2. No real model has been loaded: MLX loading, speed, memory, quantisation quality, real prompt-injection resistance and non-English answer quality are unmeasured. Claims about the model line-up remain the owner's recorded decisions, not measurements.
3. Criterion 5 deviation (Finance/Health authorised path denied by current policy) and criterion 7 gap (typed capabilities unreachable) need architect decisions; see rows 5 and 7.
4. The consent and index-status routes are specification-only; sources are designated through the internal store, not through a served route.
5. Retrieval is lexical; Japanese and other unspaced scripts are not retrievable (recorded in the evaluation as a known gap). Search time grows with the amount indexed (see the benchmark).
6. No public-web egress gateway exists; nothing in this slice contacts the network.
