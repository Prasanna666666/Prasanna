# Egress gateway for public research (Stage 3, `egress.py`)

Requirement: STAGE-3-EXECUTION-PLAN.md ("Public Internet research through the Core egress gateway when useful, using synthetic fixtures in CI and never sending private owner data to public search") and
INTERNET_AND_NETWORK_POLICY.md sections 1-3, 7, 8. Status: **implemented and tested with synthetic fixtures; exposed through the separate API 1.1 research operation behind two explicit gates, both OFF by default; not integrated into ordinary answer generation; never run against the real Internet; public search stays disabled until the final-stage gates (F-11) pass.**

## What it enforces
- **Controlled network boundaries.** The architecture test currently permits six network-capable modules for distinct purposes: `egress` (public research), `transport` (local Unix socket), `confinement` (negative sandbox probes), `connector_transport` (owner-addressed integrations), `relay` (paired-device channel) and `browser_engine` (isolated page reading). These are not interchangeable egress paths. Model modules cannot open network connections directly (`tests/test_architecture.py::test_only_the_egress_gateway_and_the_local_transport_can_open_a_network_connection`).
- **Typed operations:** `search(query, taint)` and `fetch(url, taint)`. Both refuse with a code (`Denied.code`) and send nothing when a check fails.
- **No private data out.** A task's `TaintSet` stores fingerprints, not the text: 4-word and 2-word runs from both the question and resolvable passages, and individual words of 4+ letters from both (excluding a fixed English/Dutch stop-word list). It also fingerprints identifier-like tokens containing digits or `@`, and proper-name-like words. This deliberately over-refuses queries sharing private content words. A query or URL (including host, path, query and fragment) matching those fingerprints is refused (`private_content_in_request`); e-mail addresses, long numbers and identifier-like tokens are refused (`identifier_in_request`); and a task whose scope/context contains Finance or Health data may not use the network (`restricted_context`, G-021). **Residual gap:** 1–3-character private terms and paraphrases are not guaranteed caught (ATLAS-SEC-014). `TaskService.research()` currently skips a saved passage if its source no longer resolves, so the old saved text may not be fingerprinted (ATLAS-EGRESS-091, P1); do not claim every historical private passage is covered.
- **Destination.** HTTPS only, no credentials, port 443, every resolved address public (no loopback, private, link-local, reserved, multicast or shared address space); every redirect hop is checked again, at most 3 redirects. The gateway and transport perform resolution/validation at separate points; the transport validates and connects to the address it resolved. DNS itself is not yet covered by the request deadline (ATLAS-EGRESS-077), so no bounded-DNS guarantee is claimed.
- **Content is untrusted data.** Text types only (HTML, plain text, JSON); scripts and styles are dropped from HTML; response bytes and extracted text are bounded. The current `truncated` flag does not report every extracted-text slice at 200,000 characters when the raw response is below 512 KiB (ATLAS-EGRESS-078, P1); do not rely on the flag as complete until fixed. Returned as `WebDocument` with URL, domain, retrieval time and content hash, `trust="untrusted"`, `authority="none"`. Instruction-like text is flagged (`instruction_like_text`), never obeyed: nothing the document says can cause another request, add a source, a tool, a grant or an action.
- **Audit** (`AuditRecord`): host, purpose, data class, time, status, byte count. Never a query, URL path, header or content; a refusal records that something was refused, not what.

## Not built / not verified
- **Wired, disabled.** `POST /v1/tasks/{task_id}/research` (API 1.1, additive; `ResearchRequest` / `ResearchResult`) reaches the gateway only if `CoreConfig.egress` is set AND `CoreConfig.live_network` is true; both default to off, so a default Core makes no outbound request and the route answers `forbidden`. Owner client only. The task's question and retrieved passages become the taint set; a task whose scope or context holds Finance or Health data gets no network at all. The result is returned to the client as untrusted data and is never added to the task's evidence, answer or citations. Each decision is audited as a redacted `egress.decision` event (decision, reason from a closed vocabulary, destination class; never the query or URL). Tests: `tests/test_research.py`.
- `UrllibTransport` has never touched the real Internet; the search provider URL is configuration (the default is a placeholder). robots.txt, rate limits and page-date extraction are not implemented.
- **Normalisation.** Before every check the text is read as a receiver would: percent-escapes undone (also when applied twice), full-width and compatibility forms folded, accents removed, camelCase and underscores split into words. A URL is checked as a whole: host labels, path, query and fragment, and every redirect hop. Tests: `tests/test_egress.py` (encodings, host, fragment).
- **Over-refusal by design.** A public query or URL that shares any non-stopword of 4+ letters or any two-word run with the task question or a resolvable private passage is refused. This can block research on the same topic. Not detected: paraphrases and 1–3-character terms. The stale-passage omission in ATLAS-EGRESS-091 is an additional P1 gap. No no-private-egress guarantee is claimed until real transport testing is done; the gateway stays disabled.
- The taint check is a fingerprint match, not a guarantee. It does not detect paraphrases or 1–3-character terms, and it currently omits saved passage text when source re-resolution fails (ATLAS-EGRESS-091). It over-refuses within the material it fingerprints; it is not a general no-leak guarantee.
- Approval for uploads/sends is outside this gateway: it has no operation that sends owner content anywhere.

Tests: `tests/test_egress.py` (public query with provenance and a redacted audit; private content, identifiers and restricted context refused before anything is sent; destinations; redirects; response types, bounds and
instruction-like text; private names (any case) and two-word phrases in queries and URL paths/queries; network failure without error text; fingerprints not text; mutation-checked by disabling the taint check).
