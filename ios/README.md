# Atlas for iPhone

A thin SwiftUI app over `AtlasKit` (shared with the Mac app): pairing with a pinned Core key, the owner's own Calendar, Contacts, Notes and Travel read from the Mac or from a one-week cache, edits queued offline and synced with conflicts reported, and questions answered by the Mac. The project file is generated by `xcodegen` from `project.yml`; CI generates it and builds it for the iOS simulator.

What it needs to be useful, and none of it is code: a way for the phone to reach the Mac (a private network such as a VPN, or a relay the owner runs; the channel is decision G-O14) and a Mac that shows a pairing invite (`atlas://pair?...`). See `core/docs/PLUG_IN_GUIDE.md`.

Evidence: the pairing, offline, sync, conflict and revocation behaviour runs against the real Core in `app/Tests/AtlasKitTests/PhoneTests.swift` on the macOS CI runner; the app target is compiled for the iOS simulator in the `ios` CI job. No person has used it on a phone.
